# Fotos do evento — Do Átomo à Inteligência

Envie as fotos desta pasta com estes nomes para que apareçam automaticamente na galeria do site:

- `foto-01.jpg`
- `foto-02.jpg`
- `foto-03.jpg`
- `foto-04.jpg`
- `foto-05.jpg`
- `foto-06.jpg`
- `workz-fachada.jpg` (foto da fachada do Workz)

Use JPG ou WebP (se usar WebP, atualize a extensão no HTML) e prefira imagens otimizadas para web, idealmente até 500 KB por foto. A ordem da galeria segue o número do arquivo.

A galeria já mostra espaços reservados quando as imagens ainda não foram enviadas. Assim que os arquivos com os nomes acima forem adicionados, as fotos aparecerão no lugar desses espaços.
